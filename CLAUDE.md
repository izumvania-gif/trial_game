# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

EFERON: The Other Hand — a desktop browser game (English only) about a time-looping Greek polis whose scribe Leont discovers he is a process in a simulation run by operators who are themselves unaware AI agents. The full design lives in `docs/concept.md` (written in Russian); read it before adding gameplay, story or visuals. Key design rules from it: each stage is a different genre with its own perspective and palette; the sea is the only non-dithered, non-deterministic thing in the game; the online counter/player lines are part of the plot and the game must keep working when the server is unreachable.

## Commands

Run from the repo root (npm workspaces: `apps/game`, `server`; Node >= 22.13).

- `npm ci` — install
- `npm run dev` + `npm run dev:server` — Vite client on :5173 (proxies `/api` to :3000) and Fastify server on :3000
- `npm run typecheck` / `npm test` / `npm run build`
- `npm start` — serve the built client and API from the compiled server (`DATA_DIR`, `PORT`, `STATIC_DIR`, `ADMIN_TOKEN` env vars; `ADMIN_TOKEN` enables `/admin` for moderating player notes)
- Single test file: `cd apps/game && node --experimental-strip-types --test test/save.test.ts` (same pattern in `server/`); single test by name: add `--test-name-pattern "wax tablet"`
- Open the game with `?debug` for the debug panel (time speed, jump to 23:58, stage jumps, "prep night" / "prep true" to skip to the board with the main or the true-ending state, export/wipe save); it also exposes the `Game` as `window.eferon`.

## Architecture

Client (`apps/game`, Vite + TypeScript + Three.js + inkjs, no UI framework — DOM via `ui/dom.ts`):
- `game.ts` is the orchestrator: owns the save, `DayClock`, `Knowledge`, `StoryEngine`, the seven stages and the modal UI (dialogue, lyre, carving, stele lines, endings). It runs dawn → day → midnight / Song of Return / ending → reset → dawn. The reset (`ui/ResetScreen.freeze`) snapshots the last frame (`DitherRenderer.snapshot`), carves it into 1-bit marble and sinks it, shrinking and turning, into the spiral before the log. On every reset all stages are disposed and rebuilt from a fresh `CycleState`; only `LoopMemory` survives.
- Stages (`stages/*`, interface in `stages/types.ts`) talk to the game only through `StageHost` (knowledge, memory, cycle, `notice()` for anomalies + wind, `patches()`, `loseMechanic()`, `ending()`…): `town` (third-person, vase palette, residents on schedules; `stages/town/city.ts` holds the walls with the mountain gate on three sides (Greek, after Messene: ashlar with a plain coping, no merlons, square towers with slit windows and low tiled roofs; the gate can be walked through onto a short stretch of the sacred road between rocks, `outsideRoad`, up to the boundary stone with the knot `horos`, which leads into `mountain_path`), the harbour on the sea side (the beach, the wet foreshore and the stone mole are walkable: `groundAt`/`tooDeep` give the ground height, the scribe wades slowly up to his knees and the mole's end has the knot `mole_end`; on the beach the camera turns round to face the sea — not in the last hours — and the keys follow the view, read in the turn they had when the direction was pressed so the swing never walks him back), and the torches that light up at dusk — lit windows are an emissive material ramped in `updateSky`; `stages/town/night.ts` has the nameless crowd (`content/crowd.ts`: 28 extras on deterministic day plans — market, Cleon's speech, indoors at dusk, the torch procession through the gate), the line of torches climbing the mountain, the storm face (layered billows, brows, a toothy grin that widens and opens, a low glow and clock-fixed lightning) that sinks, opens its eyes, follows the scribe and grins, wind-blown dust, the wear of the simulation (`core/wear.ts`: from the third loop, glitches fixed by the cycle number — someone repeats a step, the smoke and torches freeze, the mark ⊘ flashes on a wall, the whole city hitches while the sea keeps moving; more and stronger every loop), the camera that lifts towards the mountain from 19:00 and sways from 21:00 (not with reduced motion), and the last hour: whoever did not go up the mountain stands still at their door facing it, named residents freeze where they are at 23:00 (not Eion, who goes down to the water, nor Glaucus) and answer only through the ink knot `still(name)`; the scribe walks round people (`TownStage.free`: never into anyone, stepping away always allowed) and walkers step round him (`giveWay` moves the figure, not their day); residents who stand at the same spot are spread in a small circle so each can be talked to, and a place wins a near tie with a resident standing on it (`PLACE_BIAS`); named people are told from the crowd by their silhouettes (`content/looks.ts` → `dressFigure` in `stages/figures.ts`, after their portraits: Leont's red cloak and wax tablets, Aristion bent with a white beard, a white himation and a staff, Kora's white face and red veil, Cleon's raised arm, Eion's lyre held at his side and blindfold, the merchant in red, the priest in white, Glaucus's trident, the mask seller's pole of masks, Xenos's hood, Talia's bun, net and basket, the crier's petasos; added white and red are shared unlit `MeshBasicMaterial` paint dimmed with the night (`dimPaint`), parts worn on the back sit outside the robe, and anything meant to keep a colour must be about 0.2 m across to survive the 1/3 resolution — thinner parts read only as silhouette); houses stand on a stone socle under low-pitched tiled roofs or flat terraces; a small bone mark hangs over every place that can be looked at within 18 m, drawn through roofs (`placeMarks`), so nothing hides behind a house (shown only while the player can move; anything with `userData.hud` is left out of `DitherRenderer.snapshot`, so the carved frame and the Desk's feed never show it); walkers giving way never step into a wall; `stages/town/props.ts` places washing lines, chimney smoke, baskets, nets, statues and the agora fountain from the seed; `stages/sky.ts` is the sky dome (keyed colors: sand, a red sunset in added red, night; afterglow, seeded stars, the moon) used by the town and, in full color, by the sea), `spiral` (first-person 1-bit, ring alignment + registry of past Leonts; `stages/spiral/hall.ts` adds the columns, the tablets and lamps of past Leonts and the dust in the beam; aligning rings pulses the light and plays a chord, turning one grinds stone, water drips through the Hall's echo), `relief` (walk inside a frozen carving; the altar, fire and figures are solid circles and the walk stops inside the lit ground), `desk` (DOM-only operator terminal: tickets → patches; the office around it — flickering tubes, a window whose weather never changes, colleagues typing and sometimes sending nothing, a chime when tickets come in), `board` (tactical night plan; while the night plays the map darkens, the walkers carry torches and a candle burns down), `strikes` (five blows that remove mechanics; each blow cracks the stone, knocks chips out and hushes the world for a moment, and the lost tool breaks in half on screen via `Hud.shatter`), `sea` (full color; `stages/sea/shore.ts`: foam that washes up and drains back and the moon road — both timed by `seaRandom` — wet sand, footprints to the water, gulls, sails, rocks, and Glaucus knee-deep in the final scene, who goes under when the dialogue ends), `diary` (DOM-only real-time epilogue; paper grain, ink that settles, and light that follows the reader's own clock: dawn, day, dusk, a lamp at night). Going down into the Hall and back up is covered by `ui/Passage.ts` (the city's last frame, the dark closing in, the Hall's beam) with footsteps that gain echo.
- Content lives in `content/`: `knowledge.ts` (facts/sources/endings graph), `residents.ts` (schedules of *arrivals*: `core/schedule.ts` `departures()` sets people off early enough to be there at the time given, so the Book, the script and the clues all mean the same hour; `core/streets.ts` routes them deterministically), `leonts.ts` (registry answers; `core/registry.ts` confirms three at a time), `tickets.ts` (Desk queue and patch ids), `lexicon.ts` (stele words), `endings.ts`. Patch ids decided on the Desk take effect from the next cycle and are read with `patches()` / ink `patched()`.
- `core/save.ts` — two-layer save in localStorage (`LoopMemory` vs `CycleState`), `contentVersion` = hash of the compiled story (story change → cycle state dropped, memory kept). Bump `SAVE_SCHEMA` and add a migration when `SaveFile` changes shape; new fields with defaults in `freshMemory`/`freshCycle` are filled automatically.
- `story/*.ink` (repo root) is the English script, compiled by the Vite plugin in `apps/game/vite.config.ts` via `tools/ink.ts`. Knots are entered directly (`host.interact('stele')`); every knot ends in `-> DONE`. Narration carries no `#speaker` tag (a test checks lines that describe their own speaker). Tags: `#speaker:X`, `#mood:<neutral|joy|anger|sorrow|fear|wonder>` (the portrait's face; untagged speech gets `guessMood()` from `content/moods.ts`), `#hand`, `#log`, `#hint`, `#stage:<id>`, `#spend:<min>`, `#dejavu:<id>` (+ `^` before the cue word), `#action:carve|stele_lines|board|ending:<id>`. `learned_today(id)` tells a first time from every time after; `last_hour()` is the last hour of the day however early the wind made it (the mountain endings and Glaucus's knife use it). Game-provided EXTERNALs are declared (with fallbacks) in `story/main.ink` and bound in `Game.inkFunctions()`; they are bound non-lookahead-safe so ink evaluates them only when reached (déjà vu results depend on timing).
- `render/DitherRenderer.ts` renders at 1/3 resolution and quantizes to the stage palette with Bayer dithering; palettes with `outline` also get a normals pass, and depth/normal edges are drawn in the darkest color (the incised lines). Stages that move a camera over dithered scenery snap it to whole low-resolution pixels at the player's distance (`TownStage.snapCamera`, `StageHost.lowResHeight`); the scribe has an x-ray copy (`TownStage.addXray`: pulled towards the camera, drawn with GreaterDepth) so he shows through roofs and walls, and texture detail (paving joints, roof tiles) is kept at least a pixel wide, otherwise it swims and flickers in motion. The vase palette has four tones (lacquer, added red, terracotta, bone); the board has its own `board` palette because its painted map is unlit. Specks (dust motes) set `userData.noOutline` and `depthWrite: false` so the outline pass skips them. Anything that writes alpha 0 bypasses the dither — only the sea material (`render/sea.ts`) does, and only sea-bound things may use `seaRandom()` (the sea material, Glaucus's spot on the shore); everything else must be deterministic (`seededRng`).
- True path (docs/concept.md §4): 36 Leonts (`content/leonts.ts`), 12 shards (`content/shards.ts`, every 4 teach a stele word), the Curator's awakening on the Desk (AGENT_ID → Human Notes → the chair → directors → own USER NOTE, which opens only the sprint after the minutes were read), the double board (`core/sprint.ts`: the Curator's rollback lane during the night, `SPRINT_TURNS` = 8, Minotaur is not answered twice running), `Game.trueNightMissing()` (lists unmet conditions; shown on the failed-night card), `CycleState.finale` (the sea finale, the Wake test, the Curator's scene or an ending card still up) so a reload resumes the finale instead of losing it, the Wake test (do not press; nothing takes the keyboard focus; waiting it out leads to `story/curator.ink`, the Curator in the hut by the water, before the diary), and the epilogue (`stages/diary`, `content/epilogue.ts`, one entry per real day). "Forget everything" keeps a `BreakShard` in `localStorage['eferon.shard']` that a new game finds (the illusion of the break). Importing a wax tablet exported during the night triggers `intermediate` (BACKUP DETECTED).
- Tests (`apps/game/test`) cover the knowledge graph reachability, ink compile + fact/action references, saves, schedules, registry confirmation and the board simulation. The `?debug` panel has "prep night" to jump straight to the board.
- Polish layer: `core/settings.ts` (per-viewer settings in `localStorage['eferon.settings']`, separate from the save; O opens `ui/SettingsPanel.ts`): volumes, sound captions, large text, déjà vu without timing, reduced motion, day length (sets `DayClock.secondsPerMinute`), quality, "less meta". `engine/audio.ts` synthesizes all sound with Web Audio (the one asset file is the storm song below): place pieces on the same lyre, composed in `engine/music.ts` (sections of chord progressions in a form, melody motifs on the current chord that vary each time a section returns, bass, cadences; 1–2 minutes per pass and never an exact repeat): streets, a quick agora dance over a hand drum, a slow low port tune, sparse Phrygian notes through a stone echo in the Hall — `AudioState.place` comes from `Game.musicPlace`, and each piece resumes where it left off; places crossfade (the old piece plays on while it fades, the new one swells in from a bar start), wind driven by clock + wind, the town by the hour (`engine/ambient.ts`: birds and a rooster at dawn, cicadas in the heat, agora and tavern murmur, gulls by the port, dogs and crickets in the evening, silence in the last hour), a lyre loop that detunes near midnight, a generative sea scheduled with `seaRandom`, desk hum, rain/thunder, Karplus–Strong plucks; `play(id)` also emits captions. The lyre (R, `ui/Lyre.ts`) knows two songs: the Song of Return (▼◀▲ twice) and a hidden nod to Ocarina of Time's Song of Storms (▶▼▲ twice, taught by Eion in the tavern at night once the Song of Return is known): `AudioEngine.stormWaltz()` plays `apps/game/public/audio/song-of-storms.mp3` (the author's own harp arrangement of Kondo's Song of Storms, ~60 s, decoded on unlock with leading silence skipped) or, if it cannot load, the synthesized `STORM_WALTZ` (an original D-minor waltz), with thunder and a short shower over the city (`Game.shower`, separate from the midnight rain; only over the town) that changes nothing in the day; the track is fetched when the lyre is first raised, plays on the music volume through its own bus, and `stopStorm()` hushes it at midnight, on reset and when leaving the town. `DitherRenderer.setQuality` + frame-time watching steps auto quality down (shadows off, then 4px pixels) and never back up. `ui/meta.ts` drives the tab title / favicon / console DEV COMMENTs unless "less meta" is on.
- Dialogue UI (`ui/Dialogue.ts`): a portrait tondo beside a separate box with a nameplate, typewriter reveal (off with reduced motion), numbered choices. Portraits are procedural black-figure busts in `ui/portraits.ts` (drawn with paths at 4×, reduced by majority vote to 72 px, painted in the current stage's palette: `vase` or `marble`; the line's mood sets brows, eyelids and mouth, and a separate light mask adds shade on the side away from the light, the bust's cast shadow on the cup and a lit rim along the profile); the Curator (`frontal`) is the only one drawn facing the viewer, and the only portrait shown in the quiet dialogue at the sea; `portraitFor(#speaker)` maps speakers to them — a new `#speaker:` needs an entry there (a test checks every ink speaker). `?portraits` shows the whole sheet.
- Onboarding: a new game (cycle 1, `LoopMemory.prologueDone` false; old saves with facts or a later cycle are migrated to true) opens on `ui/ColdOpen.ts` (~23 s, no words of instruction: the carved day sinking into the spiral, dawn on the wax tablet, "Don't look at the sky. Look into the stone." writing itself, "Who wrote this?"; Esc/Space/Enter or Skip) and then the prologue stage `house` (`stages/house/HouseStage.ts`, `story/prologue.ink`): the scribe's study, courtyard and vestibule, walked in steps — walk → the tablet (`other_hand`) → the chronicle (C) → Eion humming by the cistern, who teaches déjà vu on his song of the ages and tells his day → the Book (B) → the front door (`#stage:town`); opening a panel or just walking on both advance a step, and Esc offers to skip it all (a small modal that holds every other key; Enter skips, Esc stays; a skipped house marks no lessons as taught, so the town's guide and tips still come, and `prologue_shard` still shows a broken game's first shard line, which the tablet shows when played). The cold open holds every key while it plays (the house's first lines wait under it) and opens on the still dawn with reduced motion. A reload inside the house resumes it without the cold open, the step rebuilt from what is known (`other_hand`, Eion's Book entries); a save in the house is never migrated past the prologue. `Hud.coach()` is the one line at the bottom saying what to press now (the prologue only); `Hud.setGoal()` (`Game.updateGoal`) is the chip at the top with the first open question and "C — where to look". `StageHost` gives stages `openPanel()`, `coach()` and `prologueDone()`. The clock ring sits top right. In the first two cycles a red marker hangs over the star stele until its name is known.
- Guides (`content/guides.ts`, `ui/Guide.ts`): a how-to card the first time the player is free in each stage (H shows it again), small tips for new mechanics (déjà vu, chronicle, book, wind, masks, the first reset); seen ids live in `LoopMemory.guides`, the `tips` setting turns them off. The Book of Strangers (`ui/Book.ts`) writes what someone does only once it has been seen, but lists the time and place of every part of their day and marks the one that is now; each person has a portrait and a strip of the day (after Majora's Mask's notebook) under an hour scale, bone where it has been seen, with a line for now. The registry opens on a 4×9 timeline of the thirty-six, oldest scratches first, then the player's own days (`registryTimeline`).
- After Inscryption: every reset carves the player's own day (`content/days.ts`: `daySummary` of the subjects looked into, the word cut and how it ended, plus a 96-px thumbnail of the carved last frame from `ResetScreen.freeze`'s `onRelief`) into `LoopMemory.days` (the last eight, `DAYS_KEPT`); the reset screen shows it under CARVED ON THE SPIRAL and the registry keeps them as the last ring. A worn mask talks (`content/maskVoices.ts`): once a day before certain knots it says a line under its breath, as a quiet toast (lines about an hour — `when: 'evening' | 'last_hour'` — wait for it, and nothing is said where the HUD is hidden, so a line is never used up unseen). Going up to the Desk from the town or the Hall, the city's last frame shrinks into the terminal's MODULE FEED (`Game.zoomLayer`, `StageHost.lastFrame`) and grows back on the way down (not with reduced motion). Objects cross the layers: the ⊘ as the Desk's power sign, the Extinguisher's water jar on the Desk, the Curator's chair as Leont's creaking stool at dawn, the Curator's dark glasses on the diary's table. Each kind of anomaly raises the wind once a day (`CycleState.noticed`); each new gust toasts the new time of midnight, and the wind chip shows it. `STAGE_CONTROLS` feeds the bottom-left keycap bar; prompts and controls use the "KEY — label · KEY — label" format rendered by `ui/keys.ts`. Text never sits directly on a dithered view: HUD pieces are chips on `--panel`, and the CSS tokens in `style.css` keep small text at 4.5:1 or better.
- The chronicle (C) opens full screen as a map painted like a cup (`ui/ChronicleMap.ts`, data in `content/subjects.ts`, after Outer Wilds' rumour mode): every fact sits on one of 17 subject cards; a known fact that leads (by the graph's sources, or a question's first step) to a fact of another subject draws an arrow; a subject only pointed at is a black rumour card with a question mark; clicking a card lists what is written and, behind "Show hint", where to look next (`nextOnCard`: the first fact whose way in is open, with its thread clue; `openOnCard` tells a card whose rest can be found without a clue from one that waits on another; `shard_*` facts stay quiet on the map until `board_played`). Arrows into finished subjects are drawn faint; cards of people carry their portrait; `LoopMemory.mapSeen` marks what is new since the map was last open, "!" marks a card with more to find whose way is open, and "✎" a conclusion to draw (`content/deductions.ts`, after The Case of the Golden Idol: fill the gaps of one sentence at a turn of the story; right answers are kept in `LoopMemory.deductions` and write a margin note, wrong ones cost nothing); "Where next?" steps through the cards with something to do (more to find, then rumours, then conclusions; "n of N" and the hint shown at once) and a new day opens the chronicle on the first of them; the arrow keys walk from card to card (a direction cone, and the opposite arrow always goes back; selection follows focus, only the open card is in the Tab order, the chronicle focuses it on opening), the open card lists its connected cards as buttons and its own arrows are drawn strong while the rest step back; rumours are named after where they were heard of; the full-screen panel is a modal dialog with Tab kept inside, the tabs are a proper tablist (←/→), Esc works even from a word box; cards can be dragged (pointer capture; a press that barely moves is a click, and `click` opens a card so Enter/Space and screen readers work) or moved with Shift + arrows, and the layout is kept in `LoopMemory.mapLayout`, with "Tidy up" (and Undo) to put them back; the map zooms (− / + buttons, the − and + keys, Ctrl + wheel; 100–250%, kept between openings) inside a scrolling window that keeps the open or focused card in view, and a Find box (/ from anywhere on the map) lights up the cards whose name or written facts hold every word, dims the rest, marks the words in the open card, and Enter steps through the matches (Esc empties the box first) and a legend of the marks and arrows under the map; card labels scale with the board (`container-type`), so large text enlarges the open card, not the map; "new" marks are measured against `mapSeen` as it was when the chronicle opened (`MapHooks.seen`), so switching tabs keeps them; cards carry a spoken `aria-label` (state, marks, where their arrows go) and the open card is a polite live region; a second tab keeps the list of questions. While the map is open the controls bar is hidden and toasts sit top-centre; C closes it, B switches to the Book, and keys typed in a `<select>` never reach the game (`engine/input.ts`). A test checks every fact is on exactly one card, cards don't overlap, and learning everything completes every card.
- Threads (`content/threads.ts`): the questions tab of the chronicle is organised as open questions over the knowledge graph — each thread opens on some facts, lists the facts that bear on it, says where to look next (its own clue, plain about where and when; the riddling dawn note from `content/hints.ts` only when a step has no clue — hidden behind a "Show hint" button; a revealed hint is remembered per step in `LoopMemory.hintsShown`) and closes on one fact; after the first night four more open for the true path (the archive of 36, the twelve shards, Aristion's trust for the Hall door, the Curator's awakening); `UNLOCKS` are a few quiet margin notes in Leont's voice for turns that are easy to miss (no keys — mechanics belong to the guides and tips). When a fact is learned the HUD queues "In the margin" / "New question" / "Answered" toasts; `LoopMemory.learnedOn` records the cycle of each fact, and every new morning shows a recap card (what yesterday taught, what it opened, what is still unanswered). A test walks the graph to prove every thread opens, always has a next step, and closes.
- Agent mode (`?agent`, `src/agent/`): the game for AI agents. `virtualTime.ts` replaces `performance.now`, `requestAnimationFrame` and the timers with a virtual clock (installed in `main.ts` before the game is built), so nothing moves between calls; settings are forced to no sound, déjà vu without timing, reduced motion, no tips, and the stage guides are marked seen. `bridge.ts` (`AgentBridge`, exposed as `window.eferonAgent`) gives `observe()` (the stage and hour, the stage's own description, the dialogue line and choices, the text of every open card/panel, events since the last look — toasts and captions are tapped — and the actions) and `act(id, arg)` (does it, then `settle()`s: advances frames, yielding to the browser every few so promises and fetches resolve, until nothing is busy — a reset waiting for Wake, a passage, a night being played; a déjà vu line waits for the agent). Actions: the dialogue (`continue`, `say:<n>`, `finish`), every visible button/select/field (`ui:`/`choose:`/`type:` + a slug of its label), game-wide (`chronicle`, `hint <n>`, `book`, `mask`, `lyre`, `save`, `wait` seconds) and the stage's own via the optional `Stage.agent(): StageAgent` (`describe/actions/perform`): the town walks by the street graph (`route`, time spent by `SPEED` and `secondsPerMinute`; `go:<place>`, `meet:<resident>`, `talk:<resident or place knot>`, `wait` minutes, `wait_until HH:MM`), the Hall lists carvings by angle and turns rings (`turn:<ring> <degrees>`, `study <id>`, `registry`, `touch_mark`, `leave`), the board draws an ASCII map and places allies (`place:<ally> c,r`, sharing `placeAlly` with the click), the burning Hall strikes ages (`strike:<age>`, sharing `strike()`), the relief approaches its voices; DOM stages are read from the screen (the Desk adds only `leave`, for Esc; its queue items are real buttons); `wait` is offered on every screen outside a dialogue line, since the Wake test is passed by doing nothing; reading the chronicle or the Book counts as opening it for the prologue (`HouseStage.panelRead`). The top-level `agent/` folder (not a workspace; own `package.json` with Playwright) runs it: `game.mjs` (`EferonGame`: serves `apps/game/dist` on the fixed `127.0.0.1:7358` — the save is localStorage, bound to the origin — or `--url`, with a persistent Chromium profile), `eferon.mjs` (`serve` HTTP on :7357, `observe`/`act`/`new`/`save`/`load`/`shot` CLI, `mcp` stdio MCP server with observe/act/new_game/load_tablet), `selftest.mjs` (every stage through observe/act; run it after changing a stage's controls), `README.md`.
- All server calls go through `src/api.ts` and must fail soft (return `null`).

Server (`server`): Fastify app built in `src/app.ts` — `/api/counter` (global CYCLE RUN), `/api/stele` (lines built only from the fixed vocabulary in `src/stele.ts`, rate-limited per IP) and `/api/notes` (free-text notes from the epilogue, filtered in `src/notes.ts` and premoderated: only admin-approved notes are ever returned; `/admin` + `/api/admin/*` exist only when `ADMIN_TOKEN` is set) (`buildApp` takes a `Store`, so tests use `openStore(':memory:')` + `app.inject`). Persistence is `node:sqlite` (built-in, no native deps) in `src/db.ts`; the DB file is `$DATA_DIR/eferon.sqlite`. The server also serves `apps/game/dist` with an SPA fallback. Server TS runs directly via Node type stripping in dev/tests (hence `.ts` import specifiers and `erasableSyntaxOnly` — no parameter properties or enums) and is compiled with `tsc` for production. The global cycle counter starts at `CYCLE_RUN_FIRST = 1472` (the prologue's cycle number).

## Deploy

Pushes to `main` run `.github/workflows/ci.yml` (typecheck, tests, build, Docker build + smoke test). Amvera builds the root `Dockerfile` per `amvera.yml` (docker environment, persistent mount `/data`, port 3000) and deploys on the GitHub "Workflow runs" trigger, so only green CI deploys. The Dockerfile copies `apps/game`, `server` and `story` explicitly — add new top-level source dirs there.
